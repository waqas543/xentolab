# OSM Companies — frontend

Next.js 16 / React 19 dashboard. See the [project README](../README.md) for setup.

```bash
nvm use && npm install && npm run dev
```

- `src/app/*`: pages (overview, companies, map, analytics, query)
- `src/components/*`: filter bar, charts, maps, company drawer, query runner pieces
- `src/lib/*`: API client, URL-synced filters, types, formatting
